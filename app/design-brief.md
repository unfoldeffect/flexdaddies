# Flex Daddies — design brief

**Design read** — Two friends over 50, Diego and Kevin, logging gym sessions together on their phones between sets; needs to be fast, thumb-friendly, and readable without squinting.

**Concept spine** — a gym locker-room logbook: bold color-blocked cards, a chunky pill-button interface, plate-shaped avatars — utilitarian and a little playful, never corporate-fitness-app sterile.

**Delivery tier** — editorial (a personal utility tool used daily, not a marketing site; craft comes from typography, color-blocking, and generous touch targets rather than scroll spectacle).

**Locked palette** — navy `#0b2545` (ink/surface-dark), gold `#c9a227` (primary action/accent), white/off-white `#ffffff`/`#f6f7f1` background. Provided directly by the user (existing brand: flexdaddies.com, registered domain, existing logo) — not generated.

**Locked type** — Oswald (headings/display, bold condensed gym-signage feel) + Inter (body/UI, high readability). Both user-specified.

**Animation mode: non-animated — user picked Non-animated at intake**

**Section plan** — single-page app with three tab views (no scroll journey): Log Workout (date + exercise builder), History (filterable past sessions), Stats (totals + personal records). Profile-select gate before entry. Bottom pill nav switches views.

**Asset plan** — one asset: the user-supplied circular Flex Daddies badge logo (navy ring, gold flexing-arm illustration), reused as hero mark, favicon, and OG image. No generated imagery — this is a personal utility tool with an existing brand identity, not a marketing site needing a generated visual kit.

**CTA inventory** — "LOG WORKOUT" (save button, gold pill, own disabled/saving states), "Add Another Exercise" (dashed outline pill), profile pills ("DIEGO"/"KEVIN", own color-dot avatar), "Switch" (top-bar navy pill), filter chips (Everyone/Diego/Kevin), "Delete this entry" (inline text action, danger color). Each has its own visual treatment per the original working prototype this build replicates.
